快速入門

觀眾最常問嘅三件事

點樣賺占幣 [PTS]

  • 平時喺直播互動、傾偈、參與活動。
  • 每日可以用 !daily 領每日占幣。
  • 賭盤 [prediction]：有效落注 !bet 1 100 或 !bet 2 50 會即送 +5 占幣，每次每人只計一次。
  • 開台領占幣 [Stream Start Claim]：0 cost / 25 占幣。
  • 直播完結領占幣 [Stream End Claim]：0 cost / 25 占幣。
  • Minecraft 金錢獸 [Money Boss]：每位有參與嘅觀眾 +50 占幣，每隻 boss 最多 20 人 / 1000 占幣。

點樣用占幣

  • 兌換 Minecraft 直播事件 [redeem]。
  • 買角色裝備 [Stream Avatars gear]。
  • 參加賭盤 [prediction]，例如 !bet 1 100 或 !bet 2 50。
  • 參與其他期間限定互動活動。
如果裝備、redeem 或 points 未即時更新，通常係系統同步中。

Minecraft 兌換玩法 [redeem]

  • 用占幣觸發 Minecraft 入面嘅直播互動事件。
  • !creeper / !zombie / !skeleton / !black：如果成功擊殺 Jimpae，兌換者 +100 占幣。
  • !tnt / !lightning：如果成功擊殺 Jimpae，兌換者 +300 占幣。
  • !anvil：如果成功擊殺 Jimpae，兌換者 +25 占幣。
  • !mcroll：15 占幣抽 Minecraft 輪盤 [roulette]；如果抽中擊殺類並成功擊殺 Jimpae，兌換者 +10 占幣。
  • !totem：成功救命 +500 占幣。
  • !golem / !dog：每次擊殺 +20 占幣，有總上限。
  • !heal / !speed / 召喚動物：主要係效果／召喚本身，冇固定分數獎勵。
Server 忙嘅時候，redeem 可能會排隊、延遲，或者被安全保護擋住。

賭盤 [prediction]

  • Streamer 開一條 prediction。
  • 觀眾用 !bet 參與。
  • 有效參與會即刻有 +5 分參與獎勵。
  • 結束後，估中嗰邊會分獎金 [payout]。

MC金錢獸點玩

Tip Jar 係直播入面嘅共同集資召喚金錢獸玩法

點樣推進度

  • 觀眾用 Twitch Bits 或 YouTube SuperChat 幫 Tip Jar 加進度。
  • 目標係 25 units；進度滿咗就會召喚 Minecraft 金錢獸。
  • 換算：100 Twitch Bits = 2 units；YouTube SuperChat 會按約略 USD 換算，$1 USD = 2 units。

成功召喚後

  • 成功召喚 boss 後，有參與加進度嘅觀眾會獲得 +50 占幣。
  • 每隻 boss 最多計 20 位參與者，即最多派 1000 占幣。
  • 如果 server 忙，召喚或占幣更新可能會有少少延遲。
