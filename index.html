快速入門

觀眾最常問嘅三件事。

點樣賺占幣 [PTS]

  • 平時喺直播互動、傾偈、參與活動。
  • 每日可以用 !daily 領每日占幣。
  • 賭盤 [prediction]：有效落注 !bet 會即送 +5 占幣，每次每人只計一次。
  • 直播完結領占幣 [Stream End Claim]：0 cost / 50 占幣。
  • Minecraft 金錢獸 [Money Boss]：每位有參與嘅觀眾 +50 占幣，每隻 boss 最多 20 人 / 1000 占幣。

點樣用占幣

  • 兌換 Minecraft 直播事件 [redeem]。
  • 買角色裝備 [Stream Avatars / SA gear]。
  • 參加賭盤 [prediction]。
  • 參與其他期間限定互動活動。
如果裝備、redeem 或 points 未即時更新，通常係系統同步中。

主要玩法

Minecraft 同 prediction 規則集中喺呢度。

Minecraft 兌換玩法 [redeem]

  • 用占幣觸發 Minecraft 入面嘅直播互動事件。
  • !creeper / !zombie / !skeleton / !black：如果成功擊殺 Jimpae，兌換者 +100 占幣。
  • !tnt / !lightning：如果成功擊殺 Jimpae，兌換者 +300 占幣。
  • !anvil：如果成功擊殺 Jimpae，兌換者 +25 占幣。
  • !totem：成功救命 +500 占幣。
  • !golem / !dog：每次擊殺 +20 占幣，有總上限。
  • !heal / !speed / 召喚動物：主要係效果／召喚本身，冇固定分數獎勵。
Server 忙嘅時候，redeem 可能會排隊、延遲，或者被安全保護擋住。

賭盤 [prediction]

  • Streamer 開一條 prediction。
  • 觀眾用 !bet 參與。
  • 有效參與會即刻有 +5 分參與獎勵。
  • 結束後，估中嗰邊會分獎金 [payout]。

常見問題 FAQ

如果系統一時未反應，通常先等一陣再試。

點解我占幣未更新？通常係同步中。等一陣再重新搜尋自己個名。
點解 redeem 無反應？Server 忙、排隊、cooldown 或安全保護都可能令 redeem 延遲。
YouTube 名搵唔到？試下連 @ 一齊搜尋，或者用你 chat 入面顯示嘅名。
Twitch / YouTube 分會唔會合併？視乎系統身份配對；如果兩邊名唔同，可能會分開計。
裝備點解未出現？Stream Avatars 可能要登入、同步或重新載入 viewer.
規則同直播講法唔同？以直播當下規則為準。
