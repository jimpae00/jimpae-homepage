私隱政策

最後更新：2026-06-30

Jimpae 花生證個人頁幫觀眾核實同連結自己嘅直播身份，方便喺 Jimpae 各個直播平台查看自己嘅花生證狀態。

我哋收集嘅資料

當你登入或連結帳號時，我哋可能會儲存以下帳號識別資料同公開個人檔案資料（metadata）：

  • Twitch 用戶 ID、用戶名稱同顯示名稱。
  • YouTube 頻道 ID、頻道 handle 同頻道顯示名稱。
  • Discord 用戶 ID 同顯示名稱。
  • 連到你觀眾個人頁嘅花生證 Season。

我哋唔會收集你嘅 Google 密碼、Twitch 密碼或 Discord 密碼。

我哋點樣使用呢啲資料

我哋只會用呢啲資料去：

  • 核實你擁有你所連結嘅 Twitch、YouTube 或 Discord 帳號。
  • 喺你嘅個人頁顯示你嘅花生證 Season。
  • 將你嘅觀眾身份喺 Jimpae 各個直播平台之間連結起嚟。
  • 喺適用情況下，協助自動化花生證相關嘅 Discord 身分組（roles）狀態。

Google / YouTube 資料

如果你用 YouTube 登入，我哋會要求唯讀（read-only）嘅 YouTube 存取權，以識別你已登入嘅 YouTube 頻道。我哋只會用嚟讀取你嘅 YouTube 頻道 ID 同基本頻道資料。

我哋唔會上載、編輯、刪除或管理你嘅 YouTube 影片、播放清單、訂閱、留言或分析資料。

資料分享

我哋唔會出售你嘅個人資料。我哋亦唔會將你已連結嘅身份資料分享俾廣告商或資料經紀（data brokers）。

取消連結同刪除

喺有提供呢個功能嘅情況下，你可以喺花生證個人頁取消已連結平台。取消連結會喺你嘅花生證個人頁移除該平台身份，但唔會刪除你嘅花生證紀錄。

如需要求刪除或更正已連結嘅身份資料，請聯絡 Jimpae：jimpae00@gmail.com。

保安

身份驗證經由官方 Twitch、Google/YouTube 同 Discord 嘅 OAuth 登入流程處理。我哋只會儲存花生證個人頁系統所需嘅帳號識別資料。

聯絡

如有私隱相關問題，請聯絡：jimpae00@gmail.com
